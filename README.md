# AIEstate — Property Globe

A globe-based website that tells you whether *you* can legally buy land or a home anywhere
in the world, based on your citizenship and residency status. Where official parcel data
exists, it also marks individual plots as buyable or not.

Current stage: **research and planning.**

- [`RESEARCH.md`](RESEARCH.md): how buyer eligibility works, a country snapshot, whether
  parcel-level marking is feasible, and globe/map technology options.
- [`BUILD_PROMPT.md`](BUILD_PROMPT.md): the implementation prompt to hand to a coding session.
